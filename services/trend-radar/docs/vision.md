# Vision & 목표

## 해결하려는 문제

### 과거의 후회
- GPU, HBM 같은 기술이 부상하는 걸 미리 알았다면...
- NVIDIA, SK하이닉스 같은 주식을 일찍 샀을 텐데
- 기술 트렌드를 따라가지 못해서 투자 기회를 놓침

### 현재의 어려움
- 새로운 기술과 정보가 너무 많이 쏟아짐
- 어떤 게 진짜 중요한지 판단하기 어려움
- 이미 화제가 된 건 늦음 (모두가 알면 기회는 사라짐)

---

## 목표

> "남들이 주목하기 전에, 조용히 성장하고 있는 기술을 감지한다"

### 구체적으로

1. **얼리 시그널 감지**
   - 논문, GitHub, 뉴스에서 특정 키워드 언급 빈도 변화 추적
   - "갑자기 언급이 늘어나는 것" = 뭔가 일어나고 있다는 신호

2. **신규 키워드 자동 발견**
   - 내가 모르는 새로운 기술/용어가 등장하면 알려줌
   - 안테나를 넓게 펼쳐서 놓치지 않기

3. **체계적인 추적**
   - 섹터 → 테마 → 키워드 계층 구조
   - 흩어진 정보를 구조화해서 관리

---

## 핵심 가치

| 가치 | 설명 |
|------|------|
| **조기 감지** | 화제가 되기 전에 신호를 포착 |
| **자동화** | 수동으로 사이트 돌아다니지 않아도 됨 |
| **구조화** | 정보를 체계적으로 정리 |
| **투자 연결** | 기술 트렌드 → 투자 기회로 연결 |
