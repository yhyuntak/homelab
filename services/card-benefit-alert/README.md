# Card Benefit Alert

> 위치 기반 카드 혜택 실시간 알림 앱

---

## 📌 프로젝트 개요

GPS로 내 위치를 감지해서, 내가 가진 카드 중 어떤 카드로 결제하면 혜택을 받을 수 있는지 실시간으로 알려주는 앱

**현재 상태**: 💡 아이디어 단계 → 법률 검토 → MVP 계획

---

## 🎯 핵심 가치

```
"스타벅스 앞에 왔을 때"
→ 알림: "신한카드로 결제 시 30% 할인!"
```
