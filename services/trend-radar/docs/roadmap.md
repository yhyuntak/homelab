# Roadmap

---

## 전체 흐름

```
Phase 1 (MVP)          Phase 2              Phase 3              Phase 4
─────────────────────────────────────────────────────────────────────────
arXiv만               + 데이터 소스        + 스마트 분석         + 투자 연결
키워드 빈도           + 테마 구조화        + 자동 발견           + 의사결정 지원
Discord 알림          + 대시보드           + LLM 인사이트        + 포트폴리오 연동
```

---

## Phase 1: MVP (최소 동작)

**목표**: 가장 단순하게 동작하는 것 먼저

| 항목 | 내용 |
|------|------|
| 데이터 소스 | arXiv (AI 관련 논문) |
| 분석 | 키워드 빈도 계산, 전주 대비 변화율 |
| 알림 | Discord webhook |
| 실행 | 매일 1회 (cron 또는 수동) |

**동작 흐름**:
```
1. arXiv에서 최근 논문 수집
2. 제목/초록에서 키워드 추출
3. 빈도 계산 & 이전 데이터와 비교
4. 급증한 키워드 Discord로 알림
```

---

## Phase 2: 데이터 확장 + 구조화

**목표**: 더 많은 소스, 체계적인 관리

| 항목 | 내용 |
|------|------|
| 소스 추가 | GitHub Trending, Hacker News, Reddit, Google Trends |
| 구조화 | 섹터 → 테마 → 키워드 계층 |
| 대시보드 | 웹 UI로 트렌드 시각화 |
| 관심 키워드 | 직접 등록/관리 기능 |

---

## Phase 3: 스마트 분석

**목표**: 더 똑똑한 신호 감지

| 항목 | 내용 |
|------|------|
| 신규 키워드 발견 | 새로 등장한 키워드 자동 탐지 |
| 이상 탐지 | 평소 대비 비정상적 급증 감지 |
| 연관 분석 | "A가 뜨면 B도 뜬다" 패턴 |
| LLM 요약 | "오늘의 주목할 트렌드 3가지" 자동 생성 |
| 감성 분석 | 긍정/부정 여론 변화 |

---

## Phase 4: 투자 연결

**목표**: 트렌드 → 투자 기회 연결

| 항목 | 내용 |
|------|------|
| 테마 → 종목 매핑 | "HBM" → SK하이닉스, 마이크론 |
| ETF 연결 | 테마별 관련 ETF 추천 |
| 타이밍 분석 | 키워드 등장 시점 vs 주가 백테스트 |
| 알림 고도화 | "관심 테마 종목 -5% 하락" 등 |
| 포트폴리오 연동 | 내 보유 종목 관련 트렌드 필터링 |

## 원칙

> MVP로 빠르게 시작하고, 실제로 써보면서 확장

- Phase 1이 동작해야 Phase 2 의미 있음
- 과하게 미리 설계하지 않기
- 필요하면 추가, 안 쓰면 제거
