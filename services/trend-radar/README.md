## 핵심 아이디어

"GPU, HBM 같은 기술이 부상하는 걸 미리 알았다면 NVIDIA, SK하이닉스에 투자했을 텐데..."

**이 시스템의 목표:**
- 이미 화제가 된 건 늦음
- 아직 조용하지만, 조용히 성장하고 있는 기술/키워드를 감지
- 다음 투자 기회를 직접 발굴
