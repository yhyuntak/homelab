# Feed Hub

> 정보의 바다에서 관심 있는 콘텐츠를 자동 수집, 분석, 한 곳에서 모아보기

---

## 핵심 기능

1. **유튜브 콘텐츠 분석**: URL → 자막 추출 → 요약 → 사실 검증
2. **정보 자동 수집**: RSS, X, Reddit, 뉴스레터 등
3. **대시보드**: 한 곳에서 모아보기
4. **알림**: Slack/Discord로 중요 뉴스 전달
